# Thermal-X

Thermal-X is a thermal event detection and analysis system that uses thermal and geospatial data to identify, classify, and prioritize significant thermal events.

## Tech Stack

- React + TypeScript
- Node.js + Express
- MongoDB Atlas
- Python
- GeoJSON
- Leaflet

## Project Flow

Data Collection  
→ Data Preprocessing  
→ Thermal Event Detection  
→ Classification  
→ Priority Analysis  
→ MongoDB  
→ React + GIS Dashboard

## Project Structure

- `src/` — React frontend
- `server/` — Backend and APIs
- `datasets/` — Local datasets
- `responsibility.md` — Team responsibilities
- `THERMALX_PIPELINE.md` — Project pipeline
